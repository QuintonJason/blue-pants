# AI Collaboration Guide for Students

## Your AI Conversations Will Be Reviewed

This course encourages using AI tools like ChatGPT. However, **how you use AI matters more than whether you use it.**

Your chat logs will be submitted and assessed based on the quality of your collaboration.

---

## What We're Looking For

| ✅ Do This | ❌ Avoid This |
|-----------|--------------|
| Ask for explanations before code | Just say "write code for X" |
| Ask "why" and "how" questions | Accept answers without understanding |
| Provide context about your assignment | Give vague, one-word prompts |
| Share error messages with details | Say "it doesn't work" |
| Request code reviews | Copy-paste without modification |
| Build on previous responses | Start over repeatedly |

---

## How You'll Be Graded

| Dimension | What It Means |
|-----------|---------------|
| **Problem Articulation** | Did you clearly explain what you needed? |
| **Iteration Quality** | Did you refine your questions based on responses? |
| **Critical Evaluation** | Did you question and understand the suggestions? |
| **Code Review** | Did you ask AI to review your work? |
| **Debugging** | Did you work through errors thoughtfully? |
| **Independence** | Did you modify AI code or just copy it? |

### What Costs Points

- **Handing over the work.** Asking the AI to build a whole page, feature or file
  for you ("make my website", "give me all the code so I can copy and paste")
  lowers your Independence score each time. Asking for an *example* to learn
  from, or for help with one part, doesn't.
- **Copying code unchanged.** Code from the AI that ends up in your project
  without your own changes counts against Independence.

### What Doesn't Count Either Way

- Conversations that aren't about your code (writing a story, editing an image)
  are left out. They don't help or hurt.

Your teacher reviews every flagged message and can overrule the flag, and you
get written feedback quoting your own messages.

---

## Example: Strong Prompt

> "I need to create a responsive product card for my web design assignment. Before we write any code, can you explain the best approach for making cards that look good on both mobile and desktop? I want to understand CSS Grid vs Flexbox for this."

**Why this works:**
- States the context (web design assignment)
- Asks for understanding first
- Specific question about responsive techniques
- Shows awareness of different approaches

---

## Example: Weak Prompt

> "product card html css"

**Why this doesn't work:**
- No context about responsive requirements
- No indication of what help is needed
- Shows minimal effort

## How to Export Your Chat Logs

### Step-by-Step Instructions

1. Go to **chat.openai.com**
2. Click your **profile icon** (bottom left)
3. Click **Settings**
4. Click **Data controls**
5. Click **Export data**
6. Check your email and confirm
7. Download the ZIP file when it arrives (may take a few minutes)
8. Extract the ZIP and find **`conversations.json`**
9. Submit this file along with your final code

---

## Quick Tips

1. **Think of AI as a tutor, not a solution machine**
   - Ask it to explain CSS concepts (Flexbox, Grid, BEM)
   - Have it check your understanding of responsive design

2. **Iterate on responses**
   - If the layout isn't quite right, describe what's wrong
   - Build on what you learned about each CSS property

3. **Make it your own**
   - Add your own color scheme and styling
   - Create additional features (animations, hover effects)
   - Use meaningful class names and add comments

4. **Debug together**
   - Share your browser DevTools findings
   - Explain what you expected vs. what's rendering
   - Include the relevant HTML and CSS

---

## Remember

The goal isn't to avoid AI—it's to **use AI effectively** as a learning tool.

Students who engage thoughtfully with AI often learn more than those who try to get quick answers.
